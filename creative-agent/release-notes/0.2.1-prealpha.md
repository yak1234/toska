# Toska 0.2.1 (pre-alpha)

**If you have Toska 0.2.0:** it offers this update by itself (**Toska › Check for Updates…**). **If you have 0.1.0:**
download this version once by hand and drag it into Applications.

## New

- **Brushwork that follows the picture.** When the agent paints many strokes over an area, the strokes can now follow
  the forms in the picture instead of all running one way inside a box, stay inside the shape they belong to with a
  soft boundary, press and lift like a hand stroke, and stop where the colour changes. This is the first step of
  teaching the agent the brushwork of different painters and materials.
- **A second try after a rejected pass.** When the agent's own review undoes a pass for mechanical-looking brushwork,
  the agent now gets the reason and one more attempt, instead of stopping.

## Fixed

- Every Toska package now includes the updater. A development build could be made without **Check for Updates…**.

## Known limits

- The new brushwork is early. In our own test (repainting a Degas pastel) the review still undid the first passes;
  nothing is lost when that happens, the painting stays as it was.
- Apple Silicon Macs only, macOS 14 or later.
- This is a pre-alpha: expect rough edges, and keep copies of paintings you care about.
