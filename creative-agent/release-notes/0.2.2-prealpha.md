# Toska 0.2.2 (pre-alpha)

**If you have Toska 0.2.0 or 0.2.1:** it offers this update by itself if you allowed automatic checks when it asked.
Those two versions have no **Check for Updates…** menu item (fixed here), so if no offer appears within a day,
download this version once by hand and drag it into Applications. **If you have 0.1.0:** download once by hand.

## Fixed

- **Check for Updates… is in the menu.** It is under **Toska** in the menu bar, next to About Toska. In 0.2.0 and
  0.2.1 the item was missing.
- **Toska looks for updates by itself**, about once a day, without first asking whether it may. It only tells you
  that a new version exists: nothing is installed until you press Install.

## Known limits

- The brushwork that follows the picture (new in 0.2.1) is early. In our own test (repainting a Degas pastel) the
  review still undid the first passes; nothing is lost when that happens, the painting stays as it was.
- Apple Silicon Macs only, macOS 14 or later.
- This is a pre-alpha: expect rough edges, and keep copies of paintings you care about.
