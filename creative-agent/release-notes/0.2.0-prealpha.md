# Toska 0.2.0 (pre-alpha)

**If you have Toska 0.1.0:** download this version once by hand and drag it into Applications. From this version on,
Toska tells you when a new version is out and installs it for you (**Toska › Check for Updates…**).

## New

- **Colour mixing.** The agent's glazes, blends and wet brushes can now mix colour the way paint does instead of
  averaging RGB, so blue over yellow gives green instead of grey. Five mixing models are built in (RGB, linear light,
  perceptual, spectral and pigment), and the agent picks pigment mixing first for the brushes that support it.
  Painting that follows a reference image does not use the new mixing yet.
- **Redesigned agent panel**, with new **Layers** and **Brushes** tabs that show what the agent made and which brushes
  it used.
- **Updates.** Toska checks for a new version and installs it when you quit. It never restarts while the agent is
  painting.

## Fixed

- Wash strokes with some brushes could lose strips of paint. This was a rare timing fault in the paint engine.
- A correct first pass on an empty canvas was sometimes undone by the agent's own review as "a flat block".

## Known limits

- Apple Silicon Macs only, macOS 14 or later.
- This is a pre-alpha: expect rough edges, and keep copies of paintings you care about.
